Quick guide

  1. Describe the API or import OpenAPI JSON/YAML.
  2. Generate tests with Adaption, or create a manual suite.
  3. Edit expectations, resolve assumptions, then save a reviewed revision.
  4. Enter the target and temporary credentials. Confirm authorization.
  5. Run tests, inspect evidence, analyse failures and export reports.

Credential placeholders

For ${SECRET_TOKEN}, supply {"SECRET_TOKEN":"value"} at execution time. Never paste credentials into descriptions or arbitrary free-text fields.

Local development

This is a single-user local application. Keep it bound to loopback. Shared or internet deployment requires authentication, HTTPS and stronger deployment isolation.

Configuration

Set ADAPTION_API_KEY and optionally ADAPTION_MODEL in your local .env, then restart. The key is never shown here.
